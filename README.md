# Power BI Dashboard

## 📊 Project Overview

This project contains an interactive **Power BI dashboard** created to analyze and visualize data through interactive reports and dashboards.

The goal of this project is to transform raw data into meaningful insights using **Microsoft Power BI**, including data cleaning, modeling, calculations, and interactive visualizations.

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and data analysis
* **Data Modeling** – Relationships between tables
* **GitHub** – Project version control and documentation


## 📈 Dashboard Features

* Interactive charts and visualizations
* Data filtering using slicers
* Key Performance Indicators (KPIs)
* Data-driven insights
* Interactive report navigation
* DAX-based calculations
* Data transformation using Power Query

## 🚀 How to Use

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` file using Power BI Desktop.
4. Refresh the data if required.
5. Use the filters and interactive visuals to explore the dashboard.

## 💡 Key Skills Demonstrated

* Data cleaning and transformation
* Data visualization
* Data modeling
* DAX calculations
* Dashboard design
* Business intelligence analysis
* Interactive reporting

## 📌 Notes

The `.pbix` file may contain data sources or connections that are specific to the original development environment. If the data source is unavailable, some visuals may require the data source to be reconnected before refreshing the report.
